Commands:
about                                 | display copyright and redistribution information
abstract [steps | ministeps] ?<symbols> = <expression>
                                      | display combinator abstraction
basis step [on | off]                 | names are converted to their stored expressions as a step
birds                                 | display the pre-defined bird combinators
colorize [on | off]                   | add colors to arguments while stepping
define [captured | live] <name> [<xyz...>] = <expression>
                                      | compute and store combinators such that
                                      | <name> [<xyz...>] reduces to <expression>
dependson <name> | depends-on <name> | depends on <name>
                                      | display named bases that directly contain <name>
exit                                  | end the program
find [all] [num] ?<symbols> = <expression> | find matching pre-defined bird forms
help [brief | full]                   | display help information
key step [on | off]                   | after each step, wait for a keypress to continue
load <filename>                       | load a set-list journal from a file
quit                                  | end the program
references <captured | live>          | capture name references or follow later changes
remove <name>                         | remove a user-defined combinator name
revisions <name>                      | display every retained revision of <name>
save <filename>                       | save the set-list journal to a file
set [captured | live] <name> = [arity] <expression>
                                      | store <expression> as <name> with arity <arity> or 0
show <name | name@N | all>            | display one revision or the entire set list
single step [on | off]                | display each step of the reduction without pause
step limit <off | num>                | limit ordinary and Single Step evaluations
usedby <name> | used-by <name> | used by <name>
                                      | display named bases directly contained in <name>
