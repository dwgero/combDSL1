Commands:
about                                 | display copyright and redistribution information
abstract [steps] ?<symbols> = <expression> | display combinator abstraction
basis step [on | off]                 | names are converted to their stored expressions as a step
birds                                 | display the pre-defined bird combinators
colorize [on | off]                   | add colors to arguments while stepping
define [steps] <name> <xyz...> = <expression> | compute and store combinators such that
                                              | <name> <xyz...> reduces to <expression>
exit                                  | end the program
find [all] [num] ?<symbols> = <expression> | find matching pre-defined bird forms
help [brief | full]                   | display help information
key step [on | off]                   | after each step, wait for a keypress to continue
load <filename>                       | load user-defined combinators from a file
quit                                  | end the program
remove <name>                         | remove a user-defined combinator name
save <filename>                       | save user-defined combinators to a file
set <name> = [number] <expression>    | store <expression> as <name> with arity <number> or 0
show <name | all>                     | display one definition or the entire set list
single step [on | off]                | display each step of the reduction without pause
