Stepping Options

        

            
Single Step

            

                Runs automatically and displays every reduction until normal
                form is reached or Pause is selected. A paused evaluation can
                be resumed or cancelled.
            

            
Key Step

            

                Pauses after initial expression scanning. Press any ordinary
                key for exactly one reduction. When that reduction reaches
                normal form, the session ends immediately. Pause opens a
                dialog where the reduction can be resumed or cancelled.
            

            
Basis Step

            

                Changes how Single Step and Key Step handle named bases
                defined by compound combinators. All the bird combinators (see
                Bird Info) except S, K, I, and Y are named bases. Basis
                Step off contracts a saturated named basis directly (for
                example, Mx becomes xx). Basis Step
                on exposes its underlying definition as a separate reduction
                first (so
                Mx becomes SIIx). It may remain on
                when neither stepping mode is active; ordinary evaluation
                ignores it.
            

            
step limit <off | num>

            

                Limits each subsequent ordinary or Single Step evaluation to
                at most num reductions. Key Step ignores this
                setting. The limit is off at startup, and an explicit
                off or num is required;
                num must be greater than zero. An
                expression that reaches normal form on exactly the limiting
                reduction completes normally. Otherwise, Studio offers to
                cancel or resume; resuming continues the same expression with
                a fresh limit interval in the same Results entry. Before the
                dialog opens, any progress line is refreshed to the exact
                cumulative step count; Results then remain unchanged while it
                waits. Cancelling adds only the red [cancelled]
                line. This remains a typed command;
                there is no Step Limit button, and the setting is not written
                to saved set-list journals.
            

            
Colorize

            

                When Single Step or Key Step is active, it highlights the
                first, second, third, fourth, and fifth arguments of each
                reduction in red,
                tunic green,
                blue,
                dark orange, and
                Munsell purple, and carries those
                highlights into the reduced result. When Basis Step is on, a
                basis expansion instead highlights only the basis name before
                the step and its stored contents after the step, both in red;
                all arguments remain uncolored. After the final reduction, the
                normal form is displayed without color at the left margin.
                Colorize may remain on when neither stepping mode is active;
                ordinary evaluation ignores it.
            

        

        
Command History

        

            Completed commands and expressions are saved in this browser's
            local storage and restored when Studio is reloaded. Press
            Up Arrow or Ctrl-P to recall older entries;
            press Down Arrow or Ctrl-N to move toward
            newer entries and restore the current draft. Ctrl-O
            submits the current input and, after successful completion,
            recalls the next history entry for editing. Ctrl-D
            removes a freshly recalled entry from the displayed and persistent
            history. After the cursor or selection has moved,
            Ctrl-D resumes its normal forward-delete behavior.
            Backspace and Ctrl-H always retain their
            normal editing behavior. Consecutive submissions of the same exact
            input create only one history entry. Cancelled and timed-out entries
            are recalled without their displayed status labels. Parse errors
            are not saved.
        

        
Adding Combinators

        

            Press Tab to complete a unique prefix for
            abstract, set, define,
            the dependency commands described below, find,
            references, remove,
            revisions, show, or
            step limit, including supported command options.
            


            set [captured | live] name =
                combinator_expression

            In the first form, the expression always reduces immediately.
            


            set [captured | live] name = arity
                combinator_expression

            In the second form, arity is a number specifying
            the minimal number of arguments required for the expression
            to reduce.
            


            The parser accepts nonnegative decimal integers, such as
            0 and 42. They are stored and displayed
            as integer values. A leading + or - sign
            and floating-point forms containing a decimal point or an
            e/E exponent are parse errors. Canonical
            output separates integers
            from adjacent non-parenthesized operands. In a set
            command, a nonnegative decimal integer after = is the
            arity only when whitespace and a following expression are present:
            set Num = 2 I has arity 2, while
            set Num = 2 and set Num = 2I begin
            integer bodies. Use set Num = (2) I to force a
            leading integer body before whitespace.
            


            define [captured | live] name [symbol_list] =
                combinator_expression

            The define form accepts zero or more symbols
            (lower case letters) after the name, infers the arity from their
            count, and computes a series of combinators that will reproduce the
            combinator_expression. With no symbols, it stores an
            arity-zero basis directly. An all-lowercase token immediately before
            = is the complete basis name, as in
            define foo=x. For a one-character name that does not
            begin with a lowercase ASCII letter, the space before symbols may
            be omitted. For example, to add the Eagle bird:

            define Exyzwv = xy(zwv)
            


            The optional captured or live modifier
            on set and define overrides the current
            reference mode for that command only without changing the mode for
            later input.
            Captured references pin current revisions; live references follow
            later redefinitions. An explicit modifier is retained in the
            saved set list.
            


            User-defined combinator names created by set or
            define may be redefined. Pre-defined names are
            immutable and cannot be redefined. Every changed definition creates
            the next immutable name@N revision; equivalent
            repetitions do not. Revision numbers continue after removal and
            re-addition. The saved set list keeps every changed definition and
            removal in chronological order. A redefinition is rejected only
            when its live references would create a true cycle. Recursive
            define remains supported.
            


            show name or show all

            The show command displays the arity and combinators stored
            for name. For example, show E for
            the Eagle bird would display arity:5 BDD.
            show all displays the entire saved set list followed
            by a red [show end] marker, or
            Nothing to show without the marker when it is empty.
            


            revisions name

            Displays every retained immutable revision of the unversioned
            name in ascending version order, including revisions
            retained after the current name is removed. Each user-defined line
            begins with Name@N arity:A body and ends with either
            [captured] or [live] to identify the
            effective reference mode used when that revision was parsed; the
            current revision also ends with [current]. The latest revision of a
            removed name ends with
            [removed] instead of [current]. A
            pre-defined name has one revision ending with
            [pre-defined] [current]. The fundamental names
            S, K, I, and Y
            are unversioned and cannot be queried.
            


            remove name

            The remove command removes a user-defined combinator
            name without discarding its immutable revisions. Frozen references
            remain fixed. Live references retain the most recent target while
            the name is absent and follow the new current revision if the name
            is later added again. The removal remains in the chronological
            saved set list. Pre-defined names cannot be removed.
        

        
Reference Mode

        

            references <captured | live>

            Enter this command in the Combinator Expression or Command box to
            control how named references parsed afterward are stored when a
            set or define command has no
            captured or live modifier. References are
            captured by default. In captured mode, an unqualified
            name reference pins the current immutable
            name@N version. In live mode, an unqualified
            name reference remains live and follows later changes
            to the current version. An explicit name@N reference
            always pins that exact immutable version, regardless of the mode.
            


            show name displays the current definition, while
            show name@N displays that specific revision. A
            redefinition is rejected only when resolving live references would
            make the resulting definition graph circular. Purely frozen or
            version-qualified references cannot do so by themselves. Recursive
            define remains supported through Y. Before
            the first set, define, or
            remove, only the last explicit
            references command is
            saved. If there is none, the saved set list begins with
            references captured. Later references
            commands remain in chronological order.
        

        
Inspecting Dependencies

        

            dependson name, depends-on name, or
            depends on name

            These equivalent commands list every pre-defined or currently
            user-defined named basis whose definition directly contains
            name. The result is displayed as
            name is depended on by: names, or
            name is not depended on by anything when the list is
            empty.
            


            usedby name, used-by name, or
            used by name

            These equivalent commands list every pre-defined or currently
            user-defined named basis directly contained in name's
            definition. The result is displayed as
            name uses: names, or name uses nothing
            when the list is empty. Both kinds of dependency query exclude
            the fundamental names S, K,
            I, and Y from their results.
        

        
Abstracting Expressions

        

            abstract [steps | ministeps] ?symbol_list =
                combinator_expression

            Performs the same abstraction as define without
            creating or storing a name, and displays the resulting combinator
            expression as ?=combinator_expression without
            evaluating it. With the optional
            steps, it also displays preprocessing when that changes
            the input, every right-to-left takeout pass as
            takeout <symbol> from <before>:
                <after>, and each optimizer substitution before
            displaying the final
            ?=combinator_expression line.
            For example, abstract steps ?xy = y displays
            takeout y from y: I, followed by
            takeout x from I: KI.
            With ministeps, every recursive takeout call is shown
            in its position in the full expression as
            [takeout <symbol> from
                <sub-expression>], followed by the resolved full
            expression on a new line beginning = .
            For example, abstract ministeps ?xy = y(xy) starts
            with
            takeout y from y(xy): O[takeout y from xy], then
            displays = Ox, takeout x from Ox: O,
            and ?=O.
            Unchanged preprocessing and optimization passes are omitted.
        

        
Finding Combinators

        

            find [all] [num] ?symbol_list =
                combinator_expression

            Searches the pre-defined bird catalog for forms that reduce to the
            combinator_expression when applied to the
            symbol_list. Each answer is displayed as
            ?=bird_expression. The optional num must
            be from 1 through 4, defaults to 3, and sets the largest number of
            birds in a form. Without all, sizes are searched in
            increasing order and the search stops after displaying every answer
            from the first size that has answers. With all, every
            size from one through num is searched and every answer
            is displayed. For example, find 2 ?xy = x(yx) finds
            ?=A at size one and stops; adding all
            also searches size two. A search through four birds may take
            minutes. Pause stops a search; Resume restarts that search in the
            same Results entry. Y is excluded from the search catalog.
            Matching uses bounded normalization, so the red
            No match within search bounds response does not prove
            that no equivalent expression exists.
        

        
Saving and Loading Combinators

        

            The Save button downloads the replayable journal to your computer,
            with default filename set_list.cmb. Before the first
            set,
            define, or remove, the replayable journal
            includes only the last typed references command; if
            there is none, it starts with references captured. It
            includes every later references command, changed
            definition and redefinition, and
            removal. Replaying it preserves revision numbers and the original
            frozen or live references.
            The Load button reads a .cmb file from your computer
            and replays its definitions, removals, and reference-mode changes in
            order, applying redefinitions without confirmation.

            To Mock a

            expression or right after a ( acts like ((xy)z).
